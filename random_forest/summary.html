Random Forest — Complete Summary

1. How a single tree works
Training data
→
Try every feature + cutoff
→
Pick lowest Gini
→
Split & repeat
→
Leaves = answers
Gini impurity
Measures how mixed a group is. 0 = pure (all one class). 0.5 = maximally mixed. The tree picks splits that drop Gini the most.
Leaf labels
Decided by the training data — whichever class is the majority in that leaf becomes the label. No human chooses.
2. How the forest combines trees
One dataset
→
Random samples (rows)
→
Random features (columns)
→
Many diverse trees
→
Majority vote
Bootstrap sampling
Each tree trains on a different random draw of rows (with replacement). Some rows repeat, some are left out.
Feature subsets
At each split, only a random handful of columns are offered. Forces trees down different paths.
Majority vote
Each tree votes independently. The class with the most votes wins. For regression, the average is taken instead.
3. Training vs prediction — two separate phases
Training (model.fit)
Questions are generated. Branches are built. Cutoffs are chosen. All the learning happens here. Runs once.
Prediction (model.predict)
No new questions. No new branches. Data flows through the fixed tree and reads the leaf label. Purely mechanical.
4. Parts of a tree
Root node
First question. Chosen because it gives the biggest Gini drop across the whole dataset.
Branches
Yes/no paths out of each question. Every node has exactly two.
Internal nodes
Follow-up questions deeper in the tree. Same Gini logic, applied to the subset that arrived there.
Leaves
Endpoints. No more splits. The label is the majority class. This is the tree's answer.
5. Key parameters
n_estimators
Number of trees. More = better but slower. Can be auto-detected via OOB score. Usually 100–500.
max_depth
How deep each tree can grow. Limits complexity and reduces overfitting.
max_features
How many columns each split sees. Default √n for classification. Main source of tree diversity.
6. Why trees repeat questions — and why that's good
Trees are built independently — no communication. If one feature is dominant, most trees will use it. That's a feature, not a bug.
Standard forest (repeats allowed)
Strong features get used often. Every tree asks its best question. Diversity comes from bootstrap samples and deeper splits. In our test: 95% accuracy, 3 wrong.
Unique questions (forced diversity)
Pushes trees onto weak/noisy features. Bad trees outvote good ones. In our test: 67% accuracy, 20 wrong — 17 extra misdiagnoses.
